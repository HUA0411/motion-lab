手势与拖拽

手势是「没有按钮的按钮」，因此更需要死区、阈值与替代方案。12 个 demo 全部用 Pointer Events + setPointerCapture 实现，鼠标与触屏都能拖，并且每一个手势都配了键盘等价操作。

  • 12 个可交互 demo
  • Pointer Events + 指针捕获
  • 每项手势均有键盘替代

01

排序与删除

移动一条数据的位置或把它删掉，是列表里最危险的两个动作；两者都需要可视化阈值与退路。

01

拖拽排序（FLIP + 键盘移动）

拖动时其它项用 FLIP 让位（记录矩形 → 重排 → transform 播放差值），键盘用 Alt/⌘ + ↑↓ 移动并播报位置。

    顺序：01 → 02 → 03 → 04 → 05

    拖动任意行，或聚焦某行后按 Alt + ↑ / Alt + ↓（Ctrl + ↑ / ↓ 同样可用）

    触发
    pointerdown + pointermove（setPointerCapture）· Alt+↑↓ 键盘移动
    时长
    --dur-base 240ms（FLIP 让位）· 拖起 --dur-fast 150ms
    缓动
    --ease-out-quint
    属性
    transform: translate3d + scale · opacity（禁止 top/left）
    降级
    lite/off：重排瞬时生效；键盘替代始终可用并 aria-live 播报
