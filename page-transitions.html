展厅 D · PAGE TRANSITIONS

页面转场

转场的作用不是"炫"，而是回答一个问题：我从哪儿来、现在在哪儿。这一厅把跨文档、共享元素、模态、抽屉、全屏、视图切换与排序统一到同一套参数上。

  • 8 个可交互 demo
  • 前进 / 后退方向可辨
  • 不支持 VT 的浏览器有明确降级
  • exit = 0.68 × enter

01

跨文档转场

同一个站点里的两次点击，应该能被"看出来"是向前还是向后。这一节用真实的站内链接演示，不做任何假跳转。

01

跨文档 View Transitions

属性级开启（@view-transition: navigation auto），前进自右进入、后退反向；不支持时静默降级为普通跳转并给出提示。

当前浏览器支持 View Transitions：跨页跳转会走方向动画（前进 360ms / 后退 245ms）。 当前浏览器不支持 View Transitions：跨页跳转会立即完成，不播放方向动画——内容和导航完全不受影响。
→ 展厅 B 状态与反馈 前进方向：新页面自右滑入 → 展厅 C 滚动与叙事 同样标记为 forward → 首页 回到站点入口

data-nav-dir = forward（默认） · 本次会话已前进 0 次

A 版内容：点击按钮，观察同文档阶段的旧内容如何淡出、新内容如何进入。
触发
站内 <a> 点击（内核记 data-nav-dir=forward）/ popstate（back）
时长
进入 var(--dur-slow) 360ms；退出 calc(360ms × 0.68) = 245ms
缓动
进入 var(--ease-out-quint)；退出 var(--ease-in-quad)
属性
::view-transition-old/new(root) 的 transform: translate3d(±24px) + opacity
降级
无 VT 支持 / prefers-reduced-motion：内核把 animation-name 设为 none，退化为瞬时切换

02

元素级过渡

页面级之外，元素也能"跨状态存在"：一张卡片变成详情、一个按钮长出对话框、一次点击推出抽屉、一张图铺满全屏。

02

共享元素：卡片 → 详情

卡片缩略图与详情大图共用一个 view-transition-name，浏览器自动补出中间的位移与缩放。

状态 列表 · 共享名 pt-hero · 同一页内同名元素 1 个（必须唯一）

触发
点击卡片 / Enter；关闭按钮、Esc、点击遮罩均可返回列表
时长
var(--dur-slow) 360ms；不支持 VT 时退化为 240ms 淡入
缓动
进入 var(--ease-out-expo)；退出 calc(360 × 0.68) 配 var(--ease-in-quad)
属性
共享元素由浏览器在 ::view-transition-group(pt-hero) 内插值；其余内容 opacity
降级
无 VT：直接显示详情 + 240ms 不透明度过渡；键盘与焦点管理完全一致
03

模态从触发源展开

对话框从按钮的位置与尺寸长出来，而不是从屏幕中心冒出来——它交代了「你点的是谁」。

状态 已关闭 · 起点矩形 —

对话框渲染在 #site-overlays 中（脱离 .demo 的层叠上下文），因此不会被 demo 卡片的 overflow 裁掉。

触发
按钮点击；Esc / 关闭按钮 / 点击遮罩关闭，关闭后焦点回到触发按钮
时长
var(--dur-slow) 360ms 进入；退出 245ms
缓动
var(--ease-out-expo) 进入；var(--ease-in-quad) 退出
属性
::view-transition-new(pt-modal) 的 transform（translate + scale）+ opacity，参数由触发源矩形算出

左右两个方向各一个抽屉，走内核 ML.UI.drawer：焦点锁定、Esc 关闭、关闭后焦点还原到触发按钮。

最近打开 无 · 内核已打开次数 0

触发
按钮点击 → ML.UI.drawer({side})；Esc / 遮罩 / 关闭按钮均可退出
时长
进入 var(--dur-slow) 360ms；退出 calc(360ms × 0.68) = 245ms
缓动
进入 var(--ease-out-expo)；退出 var(--ease-in-quad)（.enter-slide-* 的 .is-closing）

05

全屏转场

缩略图铺满全屏时，浏览器为它插值出一整条"生长"路径；不支持 VT 时用缩放 + 淡入替代。

状态 缩略图 · 本次过渡 — · 实测 — ms

触发
点击缩略图 / Enter；Esc 或关闭按钮返回缩略图
时长
var(--dur-slower) 560ms（位移越大越慢，避免"甩出去"）
缓动
var(--ease-out-expo) 进入；退出 calc(560 × 0.68) = 381ms 配 var(--ease-in-quad)
属性
VT 阶段由浏览器对 pt-full 做几何插值；降级路径用 transform: scale() + opacity
降级
无 VT：全屏层以 scale(0.94) → 1 + opacity 240ms 出现，内容与关闭方式完全一致

04

原理与参数

转场的全部规则可以压成一句话：屏幕上的东西只在"位置/大小/透明度"上变化，且退出的永远比进入的快 0.68 倍。

08

路由动画原理与参数表

选一档时长、一个方向，按播放：脚本会实测退出与进入的真实毫秒数，验证 0.68 系数是否落地。

路由 A / 列表

共享元素从这里出发

退出只做 translateX(-18px) + opacity，时长 = 进入 × 0.68。

路由 B / 详情

新屏从右侧滑入

进入用 --ease-out-expo，起步快、收尾稳，避免"弹出感"。

进入
360 ms（var(--ease-out-expo)）
退出
— ms（var(--ease-in-quad)）
比值
—（目标 0.68 = var(--exit-factor)）
属性
transform: translate3d(±24px) + opacity，无其它属性参与
打断
动画进行中再点按钮：从当前 transform 直接改道，不回起点
全站转场参数表（唯一真源：tokens.css 的 --dur-* / --ease-*）
场景进入退出（× 0.68）缓动
微交互 / 按压150ms102msout-quint → in-quad
状态切换 / 列表重排240ms163msout-quint → in-quad
面板 / 抽屉 / 模态360ms245msout-expo → in-quad
页面级 / 全屏560ms381msout-expo → in-quad

为什么退出更快：用户的注意力已经离开旧内容，慢退出＝阻塞等待；快退出让新内容提前获得焦点。0.68 是"可感知但不突兀"的经验值，写死为 --exit-factor。

触发
时长单选 + 方向切换 + 播放；每次播放都会实测并写入读数
时长
可选 240 / 360 / 560 ms；退出恒为 calc(进入 × var(--exit-factor))
缓动
进入 var(--ease-out-expo)，退出 var(--ease-in-quad)
属性
transform: translate3d(±24px, 0, 0) + opacity（旧屏） / translate3d(∓24px)（新屏）
降级
lite/off：两屏直接切换，读数标注「降级：瞬时」，比值公式仍以声明值展示
