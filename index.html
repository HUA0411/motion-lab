展厅地图 · A–L

12 个展厅，一条动效主线

从一次按压的 80ms，到一次页面转场的 560ms。每个展厅只解决一个具体问题，并交出可复制的参数。

  • A

    微交互

    一次按压、一次切换的物理质感。

    • 按压 0.97 缩放，出 150ms / 回 100ms
    • 图标形变而非透明度叠加
    • 触屏没有 hover，必须有等价动作
    micro-interactions.html
  • B

    状态与反馈

    空、载、错、成四态齐备，界面永远不哑。

    • 骨架屏只在 300ms 之后出现
    • 错误 = 颜色 + 图标 + 文字三重编码
    • 乐观更新失败要能回滚
    states-feedback.html
  • C

    滚动叙事

    让滚动本身承担信息层级，不做滚动劫持。

    • 视差四层 0.04 / 0.08 / 0.12 / 0.18
    • 揭晓阈值 0.15，错开 45ms
    • 文字层永不视差，可读性优先
    scroll-motion.html
  • D

    页面转场

    跨页连续性：退出永远快于进入。

    • 退出时长 = 进入 × 0.68
    • 共享元素用 FLIP 位移，不改文档流
    • 转场期间输入不阻塞、可打断
    page-transitions.html
  • E

    导航模式

    顶栏、抽屉、命令面板与焦点管理。

    • 抽屉焦点锁定，Esc 关闭后归还焦点
    • ⌘K 面板：↑↓ 选择，↵ 打开
    • 移动端触控目标 ≥ 44px
    navigation.html
  • F

    表单交互

    校验、播报与提交态，一个都不许省。

    • 常驻 label，错误紧邻字段
    • 提交时禁用按钮 + spinner
    • 错误由 aria-live 播报，不只靠红框
    forms.html
  • G

    手势与拖拽

    指针事件统一鼠标与手指，速度决定手感。

    • 位移超过 4px 才判定为拖拽
    • 松手速度作为弹簧初速度
    • 所有拖拽必须有键盘等价操作
    gestures.html
  • H

    运动物理

    弹簧、阻尼与打断策略的实验室。

    • 四档预设：snap / standard / soft / playful
    • damping ≥ 2√(k·m) 时不过冲
    • 新目标从当前速度衔接，不回起点
    motion-physics.html
  • I

    反馈系统

    Toast、确认与重试的完整生命周期。

    • 同屏最多 4 条，hover 暂停计时
    • 危险操作二次确认，明确后果
    • 失败必须给可重试的出口
    feedback.html
  • J

    无障碍

    动效的可达性不是补丁，是设计前置条件。

    • 焦点环 2px accent + 3px 偏移
    • 触控目标 ≥ 44×44px，间距 ≥ 8px
    • reduced-motion 三档可切换
    accessibility.html
  • K

    数据可视化

    手写 SVG 图表，数据变化也有物理感。

    • 折线 / 柱状 / 环形全部零库手绘
    • 数值变化由弹簧驱动，不用硬切
    • 颜色之外必须有第二编码
    data-viz.html
  • L

    设计系统

    唯一真源：token、类名、规格标注模板。

    • 颜色 / 字号 / 间距 / 动效全 token 化
    • 对比度逐项实测并附数值
    • 交付验收清单可直接照着打分
    design-system.html

精选参数墙

六个参数，决定全站手感

曲线是真的：缓动按贝塞尔参数求点，弹簧按 k / c / m 数值积分，过冲幅度是算出来的。

01 / 06

  • 01

    进入缓动

    --ease-out-quint

    真实贝塞尔求点 · 虚线 = linear 对照

    cubic-bezier(.22, 1, .36, 1)：前 100ms 走完全程 60%，尾段极慢收束。这是「贵」的来源。

    触发
    元素进入 / 状态切换
    时长
    --dur-base 240ms
    降级
    lite：仅 opacity · off：瞬时
    展厅 H · 运动物理

  • 02

    标准弹簧

    spring standard 340 / 28 / 1

    数值积分 dt = 1/240s · 虚线 = 目标值

    ζ = c / 2√(k·m) = 0.76，实测峰值 +1.9%：眼睛读作「有重量，但不过头」。

    触发
    卡片 / 面板位移
    缓动
    stiffness 340 · damping 28 · mass 1
    降级
    reduced-motion：直接落位
    展厅 H · 运动物理

  • 03

    错开间隔

    --stagger 45ms

    6 条并行位移 · 每条 360ms · 起跑差 45ms

    30–50ms 是人眼能分辨「有序」又不觉得拖沓的区间。超过 80ms 就变成排队。

    触发
    容器进入视口（阈值 0.15）
    属性
    translateY 24px → 0 · opacity 0 → 1
    降级
    全部同时淡入，取消位移
    展厅 C · 滚动叙事

  • 04

    时长阶梯

    --dur-instant → --dur-slower

    累计完成度阶梯 · 由 5 个 --dur-* 实测值算点

    • 80ms instant · 按压收尾
    • 150ms fast · hover / 颜色
    • 240ms base · 通用微交互
    • 360ms slow · 抽屉 / 面板
    • 560ms slower · 页面级揭示

    阶跃而非连续：固定档位让 13 个页面手感一致，退出统一取 0.68×。

    展厅 L · 设计系统

  • 05

    降级三档

    data-motion = on / lite / off

    • on · 全量位移 + 缓动
    • lite · 仅 opacity 与颜色
    • off · 全部瞬时完成

    跟随系统 prefers-reduced-motion，也可手动锁定。降级不是关灯，是换一种同样体面的表达。

    展厅 J · 无障碍

  • 06

    只动合成属性

    transform · opacity · filter

    • transform / opacity · 合成层，无重排
    • width / top · 每帧重排，掉帧来源

    平滑曲线的台阶就是掉帧。位移交给 transform，尺寸交给不变形的方式表达。

    展厅 H · 运动物理

横向滚动区域：使用左右方向键切换参数卡，Home 与 End 跳到首尾。

交付流程 · 5 STEP

从研究到验收，每一步都有产物

右侧这条线随滚动生长：它是流程的进度，也是我们对「可视化交付」的态度。

  1. 01

    研究

    先看真实痛点：哪里卡顿、哪里让人猜、哪里点不到。产出问题清单与成功判据。

    • 产物 · 交互问题清单
    • 判据 · 每个问题对应可测指标
  2. 02

    规格

    把感觉翻译成参数：触发事件、时长 token、缓动曲线或弹簧三参数、动画属性、降级行为。

    • 产物 · 五段规格标注
    • 约束 · 只用 transform / opacity / filter
  3. 03

    实现

    零依赖手写：CSS 变量驱动，JS 走 rAF 与弹簧内核，所有 DOM 写入都在帧内完成。

    • 产物 · 可双击运行的真实 demo
    • 标准 · 无 console 报错、无位图
  4. 04

    验证

    四个宽度实测无横向滚动与重叠；键盘全流程走通；三档动效与双主题都不破版。

    • 宽度 · 375 / 768 / 1024 / 1440
    • 检查 · 焦点环、对比度、reduced-motion
  5. 05

    交付验收

    按清单逐项打分，附截图与测量数据。跑不通的项不许打勾，带条件交付要写明条件。

    • 产物 · 验收清单 + 测量记录
    • 边界 · 已知限制逐条列出
