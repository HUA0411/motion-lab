展厅 F · FORMS

表单交互

表单是最容易失败、也最值得打磨的界面。15 个 demo 覆盖「标签始终可见 → 失焦校验不打断输入 → 错误紧邻并汇总 → 首错聚焦 → 草稿与重试 → 危险操作可撤销」的完整链路。

  • 15 个可交互 demo
  • 错误 role="alert" 播报
  • 全部 keyboard-first

01

标签、帮助与分组

标签始终可见，帮助文本随字段绑定，分组用语义元素而不是 div 假装。

01

浮动标签（label 始终存在）

label 用 transform 上浮，占位符不承担标签职责；自动化填充与浏览器自动填充都能正确进入上浮态。

聚焦或输入后标签上浮（translate + scale）

触发
focus · input · change（含自动填充）
时长
--dur-fast 150ms
缓动
--ease-out-quint
属性
transform: translate3d + scale · color
降级
lite/off：标签瞬时跳位，仍是可见 label 与 for 绑定
02

帮助文本与 required 标记

每个字段的 .hint 用 aria-describedby 绑定，必填用文字标记（不只星号与颜色）；帮助文本可整组收起。

3–16 个字符，允许中文、字母、数字与下划线。

留空则归入「未分组」，可稍后在设置里补填。

帮助文本：显示中（aria-describedby 已接线）

触发
按钮 click（aria-pressed 切换）
时长
--dur-fast 150ms
缓动
--ease-out-quint
属性
opacity · transform: translateY(-2px)
降级
lite/off：瞬时显隐；帮助文本与 aria-describedby 同步增删
03

只读 vs 禁用

只读字段可聚焦、可选中、可复制，只是不可编辑；禁用字段不可聚焦、不参与提交，也不被读屏软件读取。

readonly：可聚焦、可复制，Tab 顺序仍包含它。

disabled：无法聚焦，读屏软件会跳过，提交时不会带上该字段。

试试 Tab 键：只读字段会获得焦点，禁用字段会被跳过

触发
Tab 遍历 · 复制按钮 click · 聚焦按钮 click
时长
焦点环 0ms（即时）· 状态文字 --dur-fast 150ms
缓动
--ease-out-quint
属性
opacity · color（无位移，避免误读为可交互）
降级
不涉及动效；图标 + 文字双通道区分两种状态
04

字段分组 fieldset / legend

用 fieldset + legend 表达分组，读屏软件会播报组名；视觉分组只是副产品。

账户信息
偏好设置

共 2 个 fieldset / 4 个字段，Tab 会按视觉顺序遍历

触发

时长
focus 时 --dur-fast 150ms（边框与底色）
缓动

属性
border-color · background-color（无位移）
降级
不涉及动效；分组语义由 fieldset/legend 原生提供
05

自动填充属性 autocomplete

同一份地址表单同时服务浏览器自动填充与手动输入；按钮演示填充后的视觉高亮与键盘可用性。

浏览器自动填充不可由脚本伪造，此处演示填充后的视觉与焦点行为

触发
按钮 click · 浏览器原生自动填充
时长
--dur-slow 360ms（高亮消退）
缓动
--ease-out-quint
属性
background-color · opacity
降级
lite/off：高亮瞬时生效，autocomplete 属性与语义不变

02

校验与错误

失焦才校验，输入时不打断；错误紧跟字段，同时提供汇总入口与首错聚焦。

06

内联校验（blur 后校验，不打断输入）

失焦时校验并播报；一旦字段进入错误态，边输入边清除错误，但绝不打断输入或抖动布局。

至少 3 个字符，可含中文。

用于接收交付通知。

等待失焦校验（输入过程中不会打断）

触发

时长
--dur-fast 150ms
缓动
--ease-out-quint
属性
opacity · transform: translateY(-2px)（错误行）· border-color
降级
lite/off：错误行瞬时出现；aria-invalid 与 role="alert" 不受影响
