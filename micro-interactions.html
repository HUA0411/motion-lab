01

按钮与指针反馈

指针一落下，界面就得回答。这一组解决「按下有没有反应」「反应跟不跟手」「触摸设备上是否仍然成立」。

01

按钮按压物理

按下压缩本体，松开由弹簧带速度回弹；键盘 Space / Enter 等效。

压缩 1.000× · 峰值 1.000× · 触发 —

触发
pointerdown / pointerup / pointercancel，键盘 keydown(Space·Enter)
时长
无固定时长，由弹簧自然收敛（≈180ms 稳定）
缓动
ML.spring 预设 snap（stiffness 520 / damping 30 / mass 0.7，无过冲）
属性
transform: scale(var(--mi-press-scale)) + filter: brightness()
降级
lite/off：不写弹簧，仅 filter + border-color 颜色反馈
02

涟漪扩散

从指针落点长出的圆形波；键盘触发时从表面中心扩散。

已生成 0 圈 · 此刻 DOM 内 0 圈

触发
内核 .ripple-host 监听 pointerdown；键盘 Enter / Space 派发合成 pointerdown 走同一条路径
时长
var(--dur-slower) 560ms，一次性，animationend 后内核自动移除节点
缓动
var(--ease-out-quint)
属性
.ripple 的 transform: translate3d(-50%,-50%,0) scale() + opacity（仅绘制层）
降级
lite/off：内核 .ripple 直接 display:none，页面改为 180ms 背景色闪烁 + 计数
03

磁吸悬停

指针进入磁场后滑块朝指针偏移，最多 10px；离开后归位。方向键可等效移动。

MAGNET ← ↑ ↓ → 移动 · Home 归位

偏移 x 0.0 px · y 0.0 px · 强度 10 px

触发
pointermove / pointerleave；键盘 ArrowUp·Down·Left·Right / Home
时长
rAF 逐帧，缓动系数 0.18/帧（≈8 帧到位）
缓动
ML.lerp 线性插值追帧（ML.schedule 驱动，到位自动停表）
属性
transform: translate3d(var(--mi-mx),var(--mi-my),0)
降级
lite/off：关闭追随，仅悬停时 opacity 描边点亮，键盘仍可移动
04

悬停下划线绘制

三种描线方向；Tab 聚焦触发同一套绘制，触摸设备用点击也能看到。

  • 左 → 右
  • 中心展开
  • 右 → 左

当前聚焦 无

触发
:hover / :focus-visible（键盘 Tab 与鼠标共享同一动效）
时长
var(--dur-base) 240ms 进入，退出 calc(var(--dur-base) * .68) ≈163ms
缓动
进入 var(--ease-out-quint)，退出 var(--ease-in-quad)
属性
transform: scaleX() + transform-origin，颜色过渡
降级
lite/off：下划线直接显示，仅保留颜色变化

02

选择与切换

开关、勾选、单选、分段——四种「状态改变」的形态。它们共同的功课是：状态必须能被看见，也要能被读屏软件听见。

05

开关（含拖动）

68×44px 触控靶面；可直接拖动滑块，位移过半即吸附。角色为 switch，含 aria-checked。

OFF

拖动位移 0 / 22 px · 最近事件 —

键盘：Tab 聚焦后 Space / Enter 切换，← → 也可切换。

触发
pointerdown → pointermove → pointerup（setPointerCapture）；keydown Space·Enter·←·→
时长
弹簧自然收敛；轨道底色用 var(--dur-base) 240ms
缓动
ML.spring 预设 snap（520 / 30 / 0.7）；底色 var(--ease-out-quint)
属性
transform: translate3d(var(--mi-switch-x),0,0) + background-color
降级
lite/off：滑块瞬移到目标位（1ms），拖动仍实时跟手
06

复选框画勾

勾是一次矢量描边，不是图片切换；含已选中与禁用两种参照状态。

已选 1 / 2 项可选项

触发
原生 input:checked（鼠标点击 / Space），焦点环由 :focus-visible 驱动
时长
描边 var(--dur-base) 240ms；盒子 var(--dur-fast) 150ms
缓动
var(--ease-out-quint)；回弹 var(--ease-spring-soft)
属性
变量 --mi-check(number, @property 注册) 驱动 stroke-dashoffset；盒子 transform + opacity
降级
lite/off：勾瞬时完整显示（无描边过程），盒子不做缩放
07

单选滑动指示器

指示块在选项之间滑移，而不是每个选项各自亮灭；radiogroup + 方向键。

指示块位移 0 px · 选中 上午场

触发
点击选项；键盘 ↑ ↓ 移动并即时选中（roving tabindex）

var(--dur-base) 240ms

08

分段控件

tablist + 滑块指示器；三个标签真实切换面板内容，方向键移动。

行高 32px · 单屏可见 14 行 · 适合高密度监控

行高 44px · 单屏可见 10 行 · 默认密度

行高 64px · 单屏可见 7 行 · 触控优先

当前标签 紧凑 · 指示器由 ML.UI.tabs 驱动（--tab-x + width）

触发
内核 ML.UI.tabs：点击 / Enter·Space 激活，← → Home End 在 tablist 内移动
时长
var(--dur-slow) 360ms（指示器）；面板淡入 var(--dur-fast) 150ms

03

反馈与状态

用户做了一件事之后，界面必须交代结果。这一组处理「进行中」「完成了」「失败了」和「别重复点」。

09

点赞爆发

欠阻尼弹簧（约 6% 过冲）+ 6 颗粒子；再点一次取消，计数实时更新。

状态 未点赞 · 弹簧过冲峰值 1.000×

触发
点击 / Enter·Space（原生 button），aria-pressed 同步
时长
弹簧收敛 ≈420ms；粒子 var(--dur-slower) 560ms
缓动
ML.spring 预设 playful（420 / 17 / 1，过冲 ~6%）；粒子 var(--ease-out-quint)
属性
心形 transform: scale()；粒子 transform: translate3d() + opacity；两层心形 opacity 交叉
降级
lite/off：不发散粒子、不做弹簧；心形只做 150ms 不透明度与颜色切换
10

星级评分（半星）

支持 0.5 步进；指针滑过即时预览，离开后回到已选值。方向键增减半星。

3.5 / 5

预览值 — · 已选值 3.5

键盘：Tab 聚焦后用 ← → 调整 0.5 星，Home = 0，End = 5。

触发
pointermove 预览 / pointerleave 复位 / click 落定；键盘 ← → Home End
时长
预览即时（0ms）；落定弹跳 var(--dur-fast) 150ms
缓动
var(--ease-spring-soft)（轻微过冲 ≤5%）
属性
填充层 clip-path: inset(静态值) 表示半星；落定仅做 transform: scale() 与 opacity

lite/off：不做落定弹跳，半星靠 clip-path 与数值文本表达（信息不丢失）

12

进度环

确定进度逐帧推进（可选暂停），也可切到不确定态；数值同时用文本与 aria 播报。

0%

状态 idle · 帧耗时上限 — ms

触发
按钮点击驱动 ML.raf 逐帧写 --mi-ring；不确定态由 class 切换
时长
全程 2400ms 匀速；不确定态 1100ms/圈（loader，允许无限循环）
缓动
确定态 linear（进度类唯一允许 linear 的场景）；不确定态 linear

04

数值与图标形变

连续量（滑块、步进器）要跟手且可微调；图标形变要用最少的属性换来最清楚的语义翻转。

13

滑块（含键盘）

拖动跟手，键盘 ← → 微调、PageUp/PageDown 大步、Home/End 到端点；role=slider。

遮罩不透明度 42%
0 100

轨道宽 0 px · 行程 0 px · 最近事件 —

触发
pointerdown/move/up（含 setPointerCapture）；键盘 ← → ↑ ↓ / PageUp PageDown / Home End
时长
拖动为逐帧即时；键盘调整后 var(--dur-fast) 150ms 收敛
缓动
键盘收敛 var(--ease-out-quint)；拖动为 0ms 跟手
属性
填充 transform: scaleX(var(--mi-val))（不改 width）；滑块 transform: translate3d()
降级
lite/off：键盘收敛瞬时，拖动仍逐帧跟手（操作必需）
14

加载按钮（防重复提交）

点击后按钮 disabled + aria-busy，重复点击被计数拦截；成功后再驻留 1.2s 复位。

状态 idle · 拦截重复点击 0 次 · 提交次数 0

刻意留了 1400ms 模拟延迟：这段时间内再点不会触发第二次提交。

触发
click / Enter；进入 loading 后置 disabled + aria-busy="true"
时长
模拟请求 1400ms；成功态驻留 1200ms；spinner 900ms/圈
缓动
图标形变 var(--ease-out-quint)；spinner linear（loader 例外）
属性
图标 opacity + transform: rotate()；文字 opacity；按钮尺寸不变
降级
lite/off：图标瞬时切换，spinner 降速到 2400ms/圈但保留（状态必需）
