        圆角、阴影，以及暗色下的「光」

        这一节的核心论点只有一句：暗色底上的阴影几乎不可见，所以抬升必须改用光或描边。

        --shadow-3 --glow-accent 仅描边

        阴影几乎消失：黑底上的黑色投影没有参照物。

        铺在 --ink-800 上（更亮的面）

        抬升手段的判断表
        场景用什么为什么
        暗色主题下的卡片提亮背景 + 描边黑底上的黑阴影没有参照物，读者看不出层次
        暗色主题下的聚焦元素--glow-accent光晕同时表达"主动作"与"当前层次"，且不产生模糊边缘
        亮色主题下的浮层--shadow-2 / --shadow-3浅色底上阴影有参照物，是成本最低的层次手段
        模态框遮罩 + 阴影（亮）或光（暗）遮罩已经把背景压暗，浮层本身只需要一点点提示
        粘性表头描边 + 不透明度渐变避免滚动时出现硬阴影切边

        03

        按钮八态矩阵

        default / hover / active / focus / disabled / loading / error / readonly。前四态真实可交互，后四态是强制演示态。

        每一态的视觉线索、语义线索与可操作性
        状态视觉线索语义线索 可点击可聚焦会被播报
        触发
        真实 :hover / :active / :focus-visible；后四态由 class 与 aria 属性强制演示
        时长
        --dur-fast 150ms（颜色与边框）/ --dur-instant 80ms（按压缩放）
        缓动
        --ease-out-quint（进入）/ --ease-snap（按压回弹）
        属性
        transform: scale(0.97) 按压、opacity、颜色；不改尺寸、不产生布局位移
        降级
        ML.reduced 时去掉缩放，只保留颜色变化；disabled / loading 的语义完全不变
